LANGKAH 2: SETUP DI VPS (Guna PuTTY/Terminal)
---------------------------------------------
Masuk ke VPS dan run:

cd boda8-fresh-code

# Setup Docker (sekali run sahaja)
docker build -t boda8-bot .

# Run Bot & Database
docker compose up -d

# Restore Database (PENTING!)
# Tunggu 10 saat lepas bot start, kemudian run:
docker cp backup.sql boda8-db:/backup.sql
docker exec -i boda8-db psql -U user -d telegram_bot -f /backup.sql
